**Workflow:** Upload Thread Dump → AI Analysis → Root Cause → Recommended Fix

- ✅ Automated thread analysis for hundreds/thousands of threads
- ✅ AI-powered Root Cause Analysis (RCA)
- ✅ Deadlock and lock contention detection
- ✅ Memory leak identification
- ✅ CPU hotspot analysis
- ✅ I/O blocking detection
- ✅ Contextual fix recommendations
- ✅ Interactive dashboard
- ✅ Historical thread dump comparison
- ✅ Custom RAG integration with company practices

### Technology Stack
- Python backend
- AI/LLM processing
- RAG (Retrieval-Augmented Generation)

- React dashboard
- PostgreSQL database

## 🚀 Getting Started

### Prerequisites
- Any modern web browser
- No installation required

### Launch the Website

**Option 1: Direct File**
```
Double-click index.html or open with browser
```

**Option 2: Local Server (Recommended)**

**Windows (Python 3+):**
```powershell

python -m http.server 8000
# Visit: http://localhost:8000
```

**Option 3: Node.js**
```bash
npm install -g http-server
http-server
```
